♻️ Re-Gen eWaste – Smart eWaste Management System
Re-Gen eWaste is a modern and user-friendly web application designed to simplify the process of e-waste management. Built using Django, Bootstrap, and jQuery, this platform allows users to:

💻 Submit electronic waste for collection

♻️ Recycle old or damaged electronics

🔁 Post and browse secondhand items

💰 Receive payments for contributed items

This project promotes environmental sustainability by streamlining e-waste recycling and enabling responsible disposal of electronics.

🌟 Features
🔐 User Registration & Login

🗑️ Submit eWaste for pickup with payment

🔄 Recycle items with proper categorization

🛍️ Secondhand Listings with images

📊 Admin Panel to manage requests and reports

📄 Report Page for viewing submitted/recycled items

📱 Responsive Design using Bootstrap

🛠 Tech Stack
Frontend: HTML5, CSS3, Bootstrap, jQuery

Backend: Django (Python)

Database: SQLite (default Django DB)

Tools: Git, GitHub, VS Code
